[2017] Interactive Attention Networks for Aspect-Level Sentiment Classification

这个模型很直接，context和target分开建模，输出向量互相算attention，最后拼在一起预测。target就孤零零一个词，其实相当于就初始化语境下的词向量，有点问题，效果一般。

[2018] Left-Center-Right Separated Neural Network for Aspect-based Sentiment Analysis with Rotatory Attention

[2018] Learning Latent Opinions for Aspect-Level Sentiment Classification

这个模型是在输入时把target部分加了个位置mask，然后bi-lstm，然后crf得到opinion vector，特别的是，添加两种正则化损失，这个值得借鉴

[2018] Aspect Level Sentiment Classification with Attention-over-Attention Neural Networks

这篇貌似是经典论文，叫AOA，是最先用于问答的，bi-lstm得到context和target向量后，算attention矩阵，再分别按行按列softmax，相当于target到context和context到target的注意力，相乘后取均值再去和原始context求attention，最后做分类。这样比起前面的分开训练简洁多了，而且增加了一次attention，相当于增加记忆了，不知道是不是这个原因

[2018] Recurrent Entity Networks with Delayed Memory Update for Targeted Aspect-based Sentiment Analysis

这个文章搞了个新的单元来除了记忆信息，大概理解是与LSTM类似但增加了一个记忆，隐状态对应这里的memory，cell state对应delay，memory和key两部分输入也有一些特别的交互。

[2018] Aspect Term Extraction with History Attention and Selective Transformation

分THA和STN两部分分别编码aspect和opinion，THA会把历史隐状态缓存，在每步用当前隐状态和缓存算注意力，同时会加上一个history-aware aspect representation，注意力权重会更新这个haar并加上当前隐状态。THA输出会传给STN，两个连接转换加和后会算一个bilinear attention，再和THA输出拼起来去做标注。这篇的基本假设是后面的aspect会和前面的相关，但真的相关吗

[2018] Transformation Networks for Target-Oriented Sentiment Classification

上篇的姊妹篇，亮点是CPT模块和包含位置的卷积，CPT是bi-lstm基础上，把target的bi-lstm结果用attention结果和每个隐状态拼接后计算，最后卷积时按距离target距离给衰减系数。

[2018] Double Embeddings and CNN-based Sequence Labeling for Aspect Extraction

这篇的贡献是证明不同embedding对序列标注的意义，只需要训练一个领域内词向量加入初始化就可以很大程度改善效果。所以初始化作用不可忽视，不要想着模型迟早能学好。

[2018] Aspect Based Sentiment Analysis with Gated Convolutional Networks

[2018] Improving Aspect Term Extraction with Bidirectional Dependency Tree Representation

[2018] Modeling Inter-Aspect Dependencies for Aspect-Based Sentiment Analysis

[2018] Exploiting Document Knowledge for Aspect-level Sentiment Classification

[2018] A Position-aware Bidirectional Attention Network for Aspect-level Sentiment Analysis

[2018] Hierarchical Attention Based Position-aware Network for Aspect-level Sentiment Analysis

[2018] IARM: Inter-Aspect Relation Modeling with Memory Networks in Aspect-Based Sentiment Analysis

核心假设也是利用预测aspect时要参考其他aspect，context和每个target拼接再送入GRU，再用attention学各个aspect影响，然后进一个循环的memory network，所有aspect输出结果作为记忆。

[2018] A Unified Model for Opinion Target Extraction and Target Sentiment Prediction

[2018] An Unsupervised Approach for Aspect Category Detection Using Soft Cosine Similarity Measure

[2019] LCF: A Local Context Focus Mechanism for Aspect-Based Sentiment Classification

[2019] Attentional Encoder Network for Targeted Sentiment Classification

包括postraining和fine tuning两个过程，重点在posttraining，用了supervised contrastive learning、review reconstruction、masked aspect prediction三个技术，分别定义了三个损失函数，最后多任务学习预训练，第一个是关注每个样本的特异程度，第二个是用denoising auto-encoder的机制生成样本，第三个是遮挡关键部分和随机部分做词预测。fine tuning部分很简单，引用了解释通过span做预测的原理文章(Ethayarajh, 2019)，把关键span平均池化和CLS池化部分拼接做分类。表3里可以看到预训练起了很大作用，这里的预训练任务是文本生成和MLM（NER应该是不行。。。），对比学习也有作用。这个方法的优势是对没有显式情感词的句子提升了识别效果。另外代码里用了标签平滑损失。

[2021] Jointly Modeling Aspect and Polarity for Aspect-based Sentiment Analysis in Persian Reviews

这篇文章可以和上篇文章的补充看，基础操作讲的更具体，jointly的实现方式是标签直接拼起来做分类。

总结

GCN的成功说明了句法关系对ABAS类有侧重点的文本分类是很重要的，但句法树要用概率矩阵，不要邻接矩阵，多层相加能提升性能。GCN和语义提取两条腿是必要的，因为标注需要语义编码。bert输出包含了丰富的上下文语义分布信息（诱导句法树的原理也是寻找对目标词影响最大的context词，是一种关联关系，但可能不应该说是句法树），相当于全局信息融合，基于句法关系的GNN（GCN、GAT等）把一个节点相关的信息再加权融合，相当于局部信息融合，而且增强了每个词的语义表达，因为再添加self attention或lstm的话性能会提升。

输入：TGCN和TDGAT里是用了[CLS]sentence[SEP]aspect[SEP]，其他都没有aspect，目的是在bert里强化aspect信息，但全局信息交换也应该不充分，所以TGCN里最后又加了LSTM，GAT里这个信息也是没用的。所以GAT输入时不用这个，这个放在语义编码里。

句法树：biaffine parser优于stanford parser，以aspect为中心修剪

RGAT和ARGCN存在本质不同，从targeted角度，RGAT是reshape依存树强调aspect的重要度和明显程度，其他连接都舍弃了，ARGCN是把aspect和每个token拼接，GAT按原有句法关系，从relation的融入角度，RGAT在算attention前就把r乘进去了，ARGCN是按一般GAT的算法得到注意力权重后，把r和注意力权重放在一起去更新上层节点，从输出角度，RGAT由于连接稀疏，下级节点的所有结果是拼接起来，最后只留下两个向量，ARGAT则是每层节点数都一致，因而RGAT没有多层能力，ARGAT可以，也避免了RGAT每次只能输入一个aspect的问题。

RGAT研究的代码是用pytorch实现的，ARGAT研究里用了torch_geometric，里面RGAT的实现和上个论文里实现有所不同，在layers/RGAT_conv.py里，依存类别向量经过多层得到一个值归一化为attention权重alpha，另外按照GAT得到每个节点特征权重，两部分加权向量拼接后分类。ARGCN的几个实现方式也不一样，ARGCN_dep_distance_conv.py是论文里的实现，跟着代码看公式就很清楚了，ARGCN_dep_conv.py里类似RGAT_conv，但是把alpha和beta加起来去做attention，最后只输出一组权重，可能问题是两组权重的权重没有考虑，ARGCN_distance_conv用了一种新的attention，把主节点、邻节点和距离矩阵连起来多头去算权重。

attention、GAT和LCF的本质都是通过一定方式的外部指导，attention是相似语义查找，GCN是句法相关筛选，LCF是限定窗口用距离筛选，这样他们的局限性就解释的通了，因为都是形而上，没有辩证看待

aspect本质上是不包含情感的，那么bert、context attention、gate、memory net等操作的目的都是在给定aspect的条件下如何把和aspect相关的词凸显出来再判断重调后信息的类别，bert每个token里包含了context信息，所以可以理解为啥很快就能学会分类，但是这个信息是没有目标导向的，因此有很多其他无关信息会干扰，这也就是为啥这个工作在bert后面加更多复杂东西会提升效果，而序列标注数据量足够时加了反而不如不加，因为这个任务的信息分布是有偏的，序列标注是要充分混匀。

那么这个任务就变成了如何找出和aspect相关的重要context，attention的问题是扁平的，bert这种起作用也与其中所蕴含的结构信息有关，GCN的问题是句法树是局部的，类似多个aspect同时说省略部分话的句子就处理不了，因此猜测难点在多跳、远距、推理的情况。
